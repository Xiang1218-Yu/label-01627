解决手机无法访问本地服务的方法

  1. 确保同一网络：手机和电脑需连接同一 WiFi / 局域网
  2. 关闭防火墙：Windows 防火墙可能阻止局域网访问，请临时关闭或添加端口放行规则
  3. 使用局域网 IP：手机不能访问 localhost，需在上方输入框中填写本机局域网 IP（通过 ipconfig / ifconfig 命令查看）
  4. 检查端口：确认服务运行在端口 {{ port }} 上且未被占用
